How a report is made

PlantSentinel runs its Java investigation pipeline: telemetry trends, anomaly detectors, the risk model, inspections and manual retrieval, then fault-signature rules. It is deterministic and uses no language model. Your text picks the machine and adds words to the manual search; it is not interpreted, so the report answers the same way whatever you ask.

To ask in your own words and get a written answer, use the Kiro assistant. Recommendations are only proposals until an engineer approves them.
