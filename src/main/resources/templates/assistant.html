How it works

Sign in to PlantSentinel with an engineer account. That is the only login this page asks for. You do not enter a Kiro password here. A viewer account can read reports but cannot send a message.

Kiro is signed in once on the computer that runs PlantSentinel (kiro-cli login). That is the host's Kiro account, not yours. Each message runs Kiro CLI there with the bas-web-assistant agent and the Auto model, and spends the host's Kiro credits. The host must also trust this project folder in Kiro. On a hosted copy the assistant stays off until the host turns it on.

Kiro gets a credential for this one answer that only works for your machines and ends with the answer.

Every tool call is checked and logged by PlantSentinel. Kiro's text is AI interpretation: check it against the evidence in the report it links to. Kiro has no shell, file or web access.
